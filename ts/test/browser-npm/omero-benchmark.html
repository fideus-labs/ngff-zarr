Notes

  • Throughput is calculated as elements processed per second (higher is better).
  • The benchmark uses synthetic Float32Array data with random values (0-65535 range, simulating 16-bit images).
  • Reservoir sampling is used for memory-efficient quantile estimation on large datasets.
  • Memory check: Tests requiring more than 50% of reported device memory (via navigator.deviceMemory) are skipped by default. Enable "Force run all tests" to override this check. Note: this may cause browser crashes or tabs to be killed on low-memory devices.
  • First run may be slower due to JIT compilation warmup.
  • Use the UI Responsiveness Test button to see how main-thread computation can block the UI compared to WebWorker-based computation.
